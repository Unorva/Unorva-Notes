# 什么是域名

> [!abstract] 一句话
> 域名是便于人记忆的互联网地址；DNS 将它解析为可路由的 IP 地址。

## 核心概念

以 `www.example.com` 为例：

| 层级       | 示例                | 作用          |
| -------- | ----------------- | ----------- |
| 顶级域（TLD） | `.com`            | 域名体系的最高层级之一 |
| 二级域      | `example.com`     | 通常由注册者持有和管理 |
| 子域名      | `www.example.com` | 可指向不同服务或环境  |

- **域名注册商**：提供域名注册、续费与管理服务。
- **权威 DNS**：保存某个域名的正式解析记录。
- **DNS 记录**：`A/AAAA` 指向 IP，`CNAME` 指向别名，`MX` 指向邮件服务器。

## 工作过程

```mermaid
flowchart LR
  A[访问 www.example.com] --> B[递归 DNS 解析器]
  B --> C[根 / 顶级域 DNS]
  C --> D[权威 DNS]
  D --> E[返回 IP 或别名]
  E --> F[浏览器连接服务器]
```

1. 用户在浏览器中输入域名。
2. 浏览器或系统先查询本地缓存；未命中则请求递归 DNS 解析器。
3. 解析器查找权威 DNS 记录并返回结果，结果会按 TTL 缓存。
4. 浏览器使用解析得到的 IP 和端口发起网络连接。

> [!tip] 实践要点
> 域名解析与网站部署是两件事：DNS 负责把名称指向目标，服务器仍需配置站点、证书和应用服务。
